ABSTRACT
THIS WORKSPACE CONTAINS THE FUNCTIONS TO 
REFERENCE $TT$OO$TT$AA$LL DATA BASE FILES.
      
> DESCRIBE
DESCRIBE

THE FOLLOWING TERMS ARE USED IN THE DESCRIPTION:

  DATA_SET_NAME: A FOUR CHARACTER NAME AS SPECIFIED
                 IN THE $SS$CC$HH$EE$MM$AA

  REFER:         A FIVE-CHARACTER REFERENCE FIELD PADDED ON THE
                 LEFT WITH COLONS AS NEEDED.

  LINKAGE:       AN EIGHT-CHARACTER LINKAGE FIELD AS DEFINED
                 BY TOTAL.

  NAME_LIST:     A SEQUENCE OF EIGHT-CHARACTER DATA ELEMENT NAMES
                 THAT MUST EXIST IN THE DBMOD.

  RECORD:        A CHARACTER STRING TO BE READ OR WRITTEN.

  DBMOD_NAME:    NAME OF THE DATA BASE DESCRIPTOR.

  FILE_NAME:     THE NAME OF THE FILE CONTAINING A DATA SET.
                 ITS FIRST TWO LETTERS WILL BE THE FIRST TWO
                 OF THE DBMOD_NAME, FOLLOWED BY THE DATA_SET_NAME.

  SCHEMA:        THE SCHEMA AS DEFINED IN THE TOTAL SINON COMMAND
                 BUT NOT TERMINATED BY 'END.'

  STATUS:        A FOUR-CHARACTER STATUS AS REPORTED BY TOTAL.

  FN:            THE FILE NUMBER ASSOCIATED WITH A DATA SET.

  KEY:           A CONTROL KEY OF A MASTER RECORD.

ALL TOTAL ERROR MESSAGES ARE REPORTED AS FOLLOWS:
20: TOTAL ERROR - XXXX  FFFFFFCCCCCCCCCC
WHERE XXXX IS THE STATUS ,  FFFFFF IS THE FILE_NAME
IN ERROR, AND CCCCCCCCCC IS A COUNT OF RECORDS PROCESSED WHEN THE
ERROR WAS DETECTED.

SINCE APL ALLOWS ONLY DYADIC AND MONADIC FUNCTIONS, THE
TOTAL FUNCTIONS MUST BE CALLED BY PRESETTING CERTAIN 
ARGUMENTS. THIS IS DONE BY THE FOLLOWING FUNCTIONS(NOTE SOME
FUNCTIONS IGNORE THE PRESET ARGUMENTS AND USE THE ARGUMENTS
SUPPLIED WHEN THEY ARE CALLED):

FILE_NAME $ISRDSN FN
REFER$ISRREF FN
REFER SREF FN
LINKAGE$ISRLINK FN
LINKAGE SLINK FN
NAME_LIST$ISRNMES FN
NAME_LIST SNMES FN

IN ADDITION:
Z$ISESTIMATE DBLOAD FILE_NAME
WILL LOAD THE DBMOD AND TOTAL IN PREPARATION FOR TOTAL USE.  ESTIMATE
IS AN OPTIONAL ARGUMENT;  IT IS COMPUTED IF NOT SUPPLIED.
ESTIMATE IS AN ESTIMATE OF HOW MUCH MEMORY WILL BE NEEDED TO COMPLETE
THE LOAD OF TOTAL AND THE DBMOD.
A DBLD B
IS A PRIMITIVE VERSION OF DBLOAD.  THE LEFT ARGUMENT IS AN ESTIMATE AND
MUST BE SUPPLIED.  THE RIGHT ARGUMENT IS THE TWO FILE NUMBERS OF THE
TIED FILES TOTAL AND DBMOD.
M$ISRNMLN FN
WILL RETURN THE LENGTH AND POSITION OF EACH
FIELD IN A DATA SET RECORD AS DEFINED BY THE DBMOD.
NAME_LIST$ISRDSNMES FN
WILL RETURN THOSE DATA ELEMENT NAMES CORRESPONDING
TO THOSE FIELDS AS DEFINED BY THE DBMOD.
